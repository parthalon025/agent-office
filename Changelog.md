# Changelog

Versions keep the `x` prefix until the design becomes a SKU.

| Version | Change |
| --- | --- |
| x1.5 | Rich chat. Messages render Markdown (links, bare URLs, bold, italic, code with copy, lists, task lists, quotes, tables, images) with a safe React renderer: no raw HTML; links http, https and mailto; images http, https and raster data URLs. `attachments` on `message`, `message.agent` and the `message` command: images (inline, grid, viewer), files (card, download), links (card), video and audio. Composer: attach button, paste and drop, file chips; `office.message(bot, text, attachments)`. Long messages collapse. Speech bubbles and the activity log show plain text. New component RichText; new icons attach and copy. Positioning: Agent Office is the control room for any agent harness and runs no agents; Concepts, Connection gives the contract, three connection patterns (Direct, Bridge, Trace), a harness table and the approval round trip. |
| x1.4 | Daily use. Since you left card (`summary`, `history`, kept in the browser), replay with a time scrubber (`replay`, `stopReplay`; live events wait), decision inbox with risk, cost and preview (`approveMany`, `declineMany`; J/K/A/D/X keys), command palette (Ctrl+K), browser alerts and a title count (Notifier, NotifyToggle), ambient bar (`ambient`). New components: SinceYouLeft, TimeScrubber, DecisionInbox, CommandPalette, Notifier, AmbientBar. `request` takes `risk`, `cost`, `preview`, `tool`; `onNotify`. `tokens.css` is now generated. Bots keep walking when the floor rebuilds. The scene centers between the HUD panels (`frameInset`, `setFrameInset`), so the elevator stays visible. The starter page runs the mock until `USE_REAL_ADAPTER`. |
| x1.3 | Manager. The Manager is an agent (`orchestrator: true`); the HQ Manager bot is now the orchestrator. The broadcast bar lists the Manager first ("Ask the Manager to do something"). New `kit/manager.js`: an optional reference orchestrator that wraps any adapter, splits a request into steps, routes each step to the best free bot, shows plan, hand-offs and result, and takes an optional `planner` (for example an LLM). `assign` takes `from`. The mock adapter takes `orchestrate: false` and finishes assigned steps. |
| x1.2 | Framework. Docs cut to README (quickstart, rules, definition of done), Recipes, Reference (generated) and Concepts; Implementation, Orchestration, Foundations, Content and Accessibility merged into them. One schema (`src/schema.json`) drives `AgentOffice.validate`, `AgentOffice.strict`, the event and command types, Reference and `kit/schema.json`. Kit: `page.html`, `adapter.js`, `part.js`, `check.py`. Sessions: `session.start`, `session.end`, `session.stop`; `sessions: "agent" \| "session"` and `isolated`; count badge, Sessions tab, SessionList component, own grey blob by elevator. Agent talk: `message.agent`; same room the bots turn or walk over, other rooms an envelope on the cable tray. `office.helpers` for custom parts. The orchestrator badge reads "Manager"; the HQ war room lead is the Manager bot. New icon: session. |
| x1.1 | Cinematic. Bots path around every object (A* nav grid, `scene-nav-pad`, `scene-nav-cell`). Post effects (bloom, highlight roll-off, vignette, fog) with `fx-*` tokens and a `quality` prop (auto, high, medium, low). Window bands per theme, a sun by the clock, a Sublevel flicker. Tower and dollhouse building view (curtain wall, roof sign, beacon, plaza, trees, elevator car). Elevator ride between floors, glass elevator on each floor, subagents arrive and leave by elevator. Living bots (blink, sway, glance, hop, slump, presenting orchestrator with a ring), contact shadows. Tool-call packets on the cable tray; token meter. Intro flythrough (`intro`). Portrait fly into the agent panel and staggered panel entrance. Optional WebAudio sound (`sound`, sound button). New icons: sound, sound-off, elevator. New library: `components/lib/three-postprocessing.js`. README sections deduplicated. |
| x1.0 | Implementation guide for agents and developers: read order, load order, mounting (React and no React), the office API, adapter steps, task recipes (roles, solutions, themes, components, copy), must rules, definition of done with visual checks, and prompt templates for Claude Code, a platform adapter, Copilot Studio and Hermes. "For agents: start here" at the top of the brand book. |
| x0.9 | Consistency pass. New tokens: `scene-subagent`, `bubble`, `on-status`, `duration-handoff`, `duration-tool-label`, `scene-handoff-dash`, `scene-handoff-gap`; the engine reads all of them. No literal colors left in the stylesheet. The mode control uses icons (day, night, terminal, tour) in place of text glyphs. Tool names over bots cut at 26 characters. One version mark across tokens, brand book, assets and scene. Consistency rules in the brand book; orchestration tokens in Foundations; orchestration notes in Accessibility. |
| x0.8 | Orchestration. Events: plan, plan.step, delegate (to a bot or a new temporary subagent), subagent.done, tool.call, tool.result (tokens, cost), knowledge, skill.load, checkpoint, rollback, trigger.run, model (fallback). Commands: delegate, rollback, cron.pause, cron.resume. 3D hand-off lines and tool names over bots. Components: AgentPanel (Chat, Trace, Agent tabs), RunTrace, ToolCall, ToolKindBadge, PlanCard, DelegationTree, ScheduleList, CheckpointTimeline, AgentCard, AgentRegistry, ChannelList, CostMeter, ModelBadge. Solutions: Hermes orchestrator, Copilot Studio agents. 25 orchestration icons. Orchestration section with the Hermes and Copilot concept map. |
| x0.7 | The 60-30-10 color rule. New `emphasis` and `on-emphasis` tokens (red in Sublevel, accent in Day and Night) for alerts, unread counts and the key action. Approve on requests uses emphasis. Each room has an alert beacon that pulses when a bot needs you or has an error. Sublevel floor colors move to the blue, purple and green structure family. ColorRatio page and a new do/don't pair. |
| x0.6 | Base components: Tooltip, Toast and ToastStack, Dialog, Tabs, TextInput, Select, EmptyState, Skeleton. Button gets danger, ghost, large, icon, loading and disabled. States shown for Button, BotRow, RoomList, AgentChat and BroadcastBar. Props tables in every component README. Motion, easing, breakpoint, scene-unit and light tokens; the 3D engine reads them. Layer tokens extended. Toasts for new requests and errors in the office. 19 new icons (7 customer solutions roles, send, chat, broadcast, pause, resume, filter, bell, close, chevrons, info, more). Sublevel bot portraits, Night and Sublevel office thumbnails, Sublevel logo. Assets follow the theme. Docs: Foundations, Content patterns, Accessibility, Changelog, Do and don't, live ContrastCheck. |
| x0.5 | Sublevel type system: Archivo, Chivo Mono and VT323. The 3D signs, labels, bubbles and screens use the theme fonts. CRT glow on figures, scan lines in chat, uppercase spaced signs. |
| x0.4 | Sublevel theme: retro-corporate tokens, fluorescent scene light, number-grid terminals, flat square panels. Mode control switches the scene and panels together. |
| x0.3 | Agent connection: adapter contract (events in, commands out), mock adapter, createAdapter helper. Chat panel, speech bubbles, broadcast bar, unread counts, connection state. Microsoft customer solutions office and seven new roles. |
| x0.2 | Office types (team, lab, studio, war room), nine role workstations, expandable building (add floors, rooms, bots), building view, box-fit camera. Icons, logos, bot portraits, office thumbnails. |
| x0.1 | The 3D office as the system: OfficeScene, BotLineup, DeskSet, FloorProps, Lounge; scene tokens; three.js. HUD components from the Agent Office x0.1 page (Panel, StatusDot, StatusBubble, Button, ModeToggle, StatusCounts, FloorList, FloorHeader, BotRow, ApprovalItem, ActivityLog, UsageMeter). |
