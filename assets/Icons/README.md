# Icons (Agent Office DS x1.6.3)

Line icons on a 24 x 24 grid with 2 px of padding (live area 2-22). Stroke is 1.75 px, round caps and round joins, no fill (small dots for eyes and LEDs are filled). The files use the ink colour `#18212b` and are for `<img>` use on light grounds. On dark grounds, do not use the files: use the inline icon component (`AgentOffice.ICONS[name]` in `src/assets.js`), which takes `currentColor`. Use the icons at 16, 20, 24 or 48 px. Do not change the stroke width. In the Sublevel theme, use the inline icons with `color: #102a33` (Sublevel ink).

`close` is a smaller x (8-16) than `decline` (6.5-17.5): use `close` for panels and dialogs, `decline` for requests. `pause` is two bars with no ring; `resting` is the status icon with a ring.

Orchestration icons (x0.8): `tool` is two meshed gears; `settings` is one gear with a hole. `mcp` is a plug, `connector` is two chain links. `checkpoint` is a bookmark on a timeline; `hq` is a flag on a pole. `rollback` is a hook arrow back to a dot; `retry` is a ring arrow. `model` is a square CPU chip with pins on four sides; `memory` is a wide memory card with pins on one edge. `schedule` is a calendar with a clock; `role-planner` is a calendar with a date grid. `plan` is a checklist with no board; `eval` is a clipboard with a check. `subagent` is a small bot with a plus; `bot` is the full bot.
