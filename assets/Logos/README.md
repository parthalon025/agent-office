# Logos (Agent Office DS x1.7)

The Agent Office mark is a rounded square (corner radius = 25% of the size) with one centred dot (diameter = 40% of the size). The wordmark is "Agent Office" in IBM Plex Sans SemiBold, converted to paths. The lockup puts the mark and the wordmark side by side. The gap is 0.4 x the mark size. The wordmark cap height is 0.5 x the mark size and the cap band is centred on the mark.

| File | Use |
|---|---|
| `mark-light.svg` | Mark on light grounds: `#18212b` square, `#e9edf1` dot. |
| `mark-dark.svg` | Mark on dark grounds: colours inverted. |
| `wordmark-light.svg` / `wordmark-dark.svg` | Wordmark only (`#18212b` / `#e9edf1`). |
| `lockup-light.svg` / `lockup-dark.svg` | Mark + wordmark. Default logo for headers and covers. |

## Clear space
Keep clear space on all sides equal to the dot diameter (40% of the mark size). For the 64 px master, this is 25.6 px.

## Minimum size
- Mark: 16 px.
- Lockup: 96 px wide.
Below these sizes, use the mark only.

## Do
- Use the light files on `bg`, `panel` or white. Use the dark files on `bg` dark or `panel` dark.
- Scale the files proportionally.
- Use the mark alone for app icons, favicons and small spaces.

## Do not
- Do not change the colours, or use the type colours or status colours on the logo.
- Do not stretch, rotate, outline or add shadows or gradients.
- Do not move the dot or change its size.
- Do not set "Agent Office" in live text as the logo. Use the outlined wordmark.
- Do not put the logo on busy 3D scene areas without a `panel` behind it.

## Sublevel theme
| File | Use |
|---|---|
| `mark-sublevel.svg` | Sublevel mark: a `#102a33` circle with a centred `#dfe6e1` dot. Same proportions as the square mark (dot diameter = 40% of the size). |
| `wordmark-sublevel.svg` | "AGENT OFFICE" in Archivo SemiBold, width 118, tracked +0.14 em, converted to paths, `#102a33`. |
| `lockup-sublevel.svg` | Round mark + Sublevel wordmark. Gap = 0.4 x the mark size. Cap height = 0.4 x the mark size (the wide caps look larger than Plex), cap band centred on the mark. |

Use the Sublevel files only in the Sublevel theme, on `bg` (`#dfe6e1`) or `panel`. Do not mix the round mark with the Plex wordmark, or the square mark with the Archivo wordmark. In code: `AgentOffice.LOGO.sublevel.mark(ink, dot)`, `.wordmarkPath`, `.wordmarkViewBox`.

Wordmark sources: IBM Plex Sans SemiBold (SIL OFL 1.1), outlined with fontTools (kerning: harfbuzz). Archivo (SIL OFL 1.1, @fontsource-variable/archivo 5.3.0), static instance wght 600 / wdth 118, outlined with fontTools (kerning: harfbuzz). Generated by `assets_src/gen_assets.py`.
