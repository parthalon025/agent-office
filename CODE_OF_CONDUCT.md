# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read it there. It applies to every issue, pull request, discussion and review in this repository.

In short: be respectful, be kind, and keep to the work. Harassment, insults and personal attacks are not accepted.

## Report a problem

Report a problem in private. Use **Report a vulnerability** on the [Security tab](https://github.com/parthalon025/agent-office/security/advisories/new) and start the report with "Conduct". The report goes to the maintainer, parthalon025, and to no one else. The maintainer answers in 7 days and handles the report as the Covenant describes.
