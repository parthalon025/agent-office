# Skeleton

A placeholder while data loads: the roster before the adapter answers, or the chat before history arrives. Match the shape of what comes next. Never show it for more than a few seconds; show an empty or error state instead.

**The consumer provides:** the number of lines and whether to show an avatar.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `lines` | no | `number` |
| `avatar` | no | `boolean` |
| `label` | no | `string` |
