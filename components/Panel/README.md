# Panel

The glass surface for every HUD block over the 3D scene. Give it an eyebrow `title` and an optional `count`. Do not nest panels. Do not put a panel on a plain page without the scene; use `chip` fill there.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `title` | no | `string` |
| `count` | no | `ReactNode` |
| `flush` | no | `boolean` |
| `className` | no | `string` |
| `children` | no | `ReactNode` |
