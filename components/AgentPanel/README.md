# AgentPanel

The panel that opens when you select a bot: a header with the bot, its role badges and model, then three tabs. **Chat** is the conversation. **Trace** is the plan, cost and every step of the run (delegations, tool calls, checkpoints). **Agent** is the agent card (identity, tools, knowledge, skills, channels).

**The consumer provides:** the bot, the messages, the steps, the plan, the cost and the handlers.
