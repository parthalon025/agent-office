# SublevelOffice

The office in the Sublevel theme: a quiet, retro corporate floor under cool fluorescent light. Green carpet, white desks, black chairs, glass partitions, and terminals that show grids of numbers. Panels go flat and square. Heads use Archivo, wide and uppercase; names and agent replies use Chivo Mono; big figures and screen numbers use VT323 with a soft CRT glow.

Any component takes the theme: set `data-theme="sublevel"` on a parent, or pass `theme:"sublevel"` to OfficeScene. In the HUD, the Sublevel button switches the scene and the panels together. The bubbles, status colors and actions do not change, so the office reads the same in every theme. For the bright, soft look, see FluentOffice.
