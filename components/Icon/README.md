# Icon

The icon set: 86 line icons on a 24px grid with a 1.75px stroke, round caps and joins. Inline icons take `currentColor`. The same icons are in `assets/Icons` as files with the `ink` color.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `name` | yes | `string` |
| `size` | no | `number` |
| `label` | no | `string` |
| `color` | no | `string` |
