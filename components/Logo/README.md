# Logo

The Agent Office mark, wordmark and lockup. The mark is a square in `ink` with one dot in `bg`; it inverts in a dark theme. Its corner is the theme's `logo-mark-radius` token (a rounded square, or a circle in Sublevel), and the wordmark is the drawing that the theme's `AgentOffice.MODES` entry names (`wordmark`). Clear space equals the dot diameter. Minimum size: 16px mark, 96px lockup.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `variant` | no | `"mark" \| "wordmark" \| "lockup"` |
| `size` | no | `number` |
| `height` | no | `number` |
