# Logo

The Agent Office mark, wordmark and lockup. The mark is a rounded square in `ink` with one dot in `bg`; it inverts in Night. Clear space equals the dot diameter. Minimum size: 16px mark, 96px lockup.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `variant` | no | `"mark" \| "wordmark" \| "lockup"` |
| `size` | no | `number` |
| `height` | no | `number` |
