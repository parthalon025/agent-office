# ColorRatio

The 60-30-10 rule, live in the current theme: 60% neutrals, 30% structure, 10% emphasis. Count the screen, not the token list. Neutrals are the background, panels, walls and desks. Structure is the carpet, panel heads, floor bands and the selected row. Emphasis is the alert beacon over a room, unread counts, and the one key action in a decision.

Source idea: "How Severance uses the 60-30-10 rule to inspire UI design" (trickle.so).
