# BotAvatar

A flat portrait of a bot for use outside the 3D scene: lists, notifications, docs. It takes the bot's shape and body color, and an optional status dot.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `shape` | yes | `Shape` |
| `color` | yes | `string` |
| `status` | no | `Status` |
| `size` | no | `number` |
