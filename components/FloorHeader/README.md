# FloorHeader

The colored head of the roster panel. Fill is the floor identity color; text is `on-floor`. Show one big `figure`: bots working now.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `floor` | yes | `FloorKey` |
| `name` | yes | `string` |
| `number` | yes | `number` |
| `bots` | yes | `number` |
| `working` | yes | `number` |
