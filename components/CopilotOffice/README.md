# CopilotOffice

The Copilot Studio office. Floor 5 holds the **Generative Orchestrator** (it plans over topics, tools and knowledge), the connected agent hub, the topic router and human handoff. Floor 4 Governance holds the evaluator, the DLP guard and the agent registry. Floor 3 Actions is a lab with agent flows, the Dataverse connector, computer use and MCP tools. Floor 2 Knowledge holds Researcher, Analyst and a grounding agent. Floor 1 Channels holds the front door, HR and IT agents.

Agents carry an identity (Entra Agent ID) and a model in the Agent tab. Names follow Copilot Studio concepts; wire them to your tenant with an adapter.
