# BuildingView

The building at a glance: every floor stacked, every room as a glass box with its office-type stripe, and every bot as a status pip that bobs while it works. Use it as the entry screen or as a mini-map. Click a floor or a room to go into it.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `building` | no | `BuildingDef` |
| `quality` | no | `Quality` |
| `simulate` | no | `boolean` |
| `controls` | no | `boolean` |
| `height` | no | `number` |
| `mode` | no | `"auto" \| "day" \| "night"` |
