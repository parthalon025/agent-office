# Workstations

The nine role workstations. The role of a bot sets its desk, its props and the picture on its screen; the status sets the screen glow.

| Role | Workstation |
| --- | --- |
| Research | Round desk, monitor with text, book stack, lamp |
| Writer | Round desk, open laptop, notepad, mug |
| Coder | Long desk, two angled monitors with code |
| Analyst | Long desk, wide monitor with a bar chart |
| Designer | Long desk, monitor, drawing tablet, easel |
| Ops | Long desk, monitor with a line graph, tower with LED |
| Sales | Round desk, funnel on screen, phone, headset |
| Planner | Standing desk, stool, kanban board |
| Media | Long desk, timeline on screen, speakers, mixer |

In a war room, all bots sit at the big table instead.

## Props

| Prop | Required | Type |
| --- | --- | --- |
| `roles` | no | `Role[]` |
| `cols` | no | `number` |
| `cycle` | no | `boolean` |
| `height` | no | `number` |
| `mode` | no | `"auto" \| "day" \| "night"` |
